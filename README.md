# 📄 Extrator de Texto PDF

> Uma aplicação web full-stack moderna e eficiente projetada para extrair, processar e gerenciar textos de arquivos PDF de forma rápida e intuitiva.

---

## 🚀 Sobre o Projeto

O **Extrator de Texto PDF** nasceu da necessidade de simplificar a extração de dados contidos em documentos PDF. Com uma interface fluida desenvolvida em **React** e um back-end robusto em **Spring Boot**, o sistema processa os arquivos de forma segura e entrega os resultados prontos para uso.

---

## 🛠️ Tecnologias Utilizadas

### **Front-end**
*   **React** (Interface de usuário dinâmica e responsiva) [Vite React 19.2.8]
*   Bibliotecas modernas para estilização e consumo de API

### **Back-end**
*   **Java & Spring Boot** (API RESTful de alta performance) (Java 17)
*   Bibliotecas especializadas em leitura e manipulação de arquivos PDF

---

## ✨ Funcionalidades Principais

*   📤 **Upload Simples:** Interface drag-and-drop ou seleção rápida de arquivos PDF.
*   ⚡ **Processamento Eficiente:** O back-end lê e extrai o conteúdo textual do documento com alta precisão.
*   📋 **Cópia e Exportação:** Facilidade para copiar o texto extraído para a área de transferência ou utilizá-lo em outros fluxos.
*   🎨 **Interface Moderna:** Design limpo, focado na experiência do usuário (UX).
